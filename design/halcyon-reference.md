# Halcyon reference-screen notes

Observed from six user-supplied screenshots on 2026-09-12. These notes describe visible interface patterns only; they do not claim anything about Halcyon's hidden data pipeline or model behavior.

## Visible patterns

1. **Document summary:** persistent metadata rail; central executive-summary card; small inline citation chips; top actions for viewing the document, download and share; prominent Query action.
2. **Document viewer:** metadata remains visible while an embedded document viewer occupies the main area; alternate action changes to View summary.
3. **Home/onboarding:** suggested alert cards and create/browse alert calls to action.
4. **Search:** a visible 7,234,845-document count; left-side filters for commission, docket number, keyword, filing type, topic and date; result cards show a generated-looking synopsis, publisher/date, source metadata, type chip and selection action.
5. **Saved queries:** run history in a left rail; long-form answer with inline citation chips; query scope/filters at right; Edit and rerun; download/share/analyze actions.
6. **Alerts:** empty state, create/browse actions and suggested packs named Large Load Highlights, Data Centers Powered by Gas and Data Center Projects, each with a cadence.

## What to adopt

- calm density and clear action hierarchy;
- persistent metadata near source content;
- citations directly attached to answer claims;
- query, download and share actions at the object level;
- editable, rerunnable saved work;
- suggested alert packs as onboarding.

## What tracker.energy advances

- citation opens the exact passage, not just the document;
- article remains readable as the primary object, with source shown on demand in split view;
- text selection inside the source starts a passage-bounded question;
- current-document evidence and wider-corpus evidence are explicitly separated;
- every citation is backed by page/passage coordinates, checksums and extraction version;
- docket chronology, party position and agency action remain distinct;
- depth, trust and workflow are optimized before raw corpus-count theatre.

## Visual design bar
The user set Halcyon's website as a direct quality bar alongside Legora and The Washington Post: clean, quiet and confident. Apply the principle, not the brand skin. Prioritize generous whitespace, restrained colour, strong editorial typography, clear hierarchy, few primary actions, consistent metadata and progressive disclosure. Avoid dashboard clutter, dense chip walls, novelty motion and fake activity. The article is the default reading surface; tools appear when invoked.
